# GachaLog PWA（初期プロトタイプ）

iPhoneでの利用を想定した、シンプルなガチャコレクションアプリの試作品です。

## 現在動く機能
- ホーム／図鑑／コレクション／発売予定／設置場所の画面切り替え
- サンプル商品6件の一覧・検索・カテゴリ絞り込み
- 商品詳細表示
- コレクション登録・解除
- 欲しいものリスト登録
- ブラウザ内（localStorage）への保存
- PWAマニフェスト・Service Worker

## 注意
商品名・メーカー・価格・画像相当の絵文字は、画面動作確認用の架空サンプルです。実在商品の情報ではありません。発売情報、地図、ログイン、クラウド同期、通知、広告・課金はまだ実装していません。

## iPhoneで試す
PWAとしてホーム画面に追加するには、HTTPSで公開する必要があります。
1. このフォルダをGitHubリポジトリにアップロード
2. VercelでリポジトリをImportしてDeploy（静的サイトとして公開）
3. 公開URLをiPhoneのSafariで開く
4. 共有ボタン →「ホーム画面に追加」

ローカルで確認する場合は、フォルダ内で簡易HTTPサーバーを起動してください（例：`python3 -m http.server 8000`）。PWA機能はlocalhostまたはHTTPSで動作します。
